## 📖 About This Course

CSE 102 – Computer Fundamentals and Programming Lab is a first-year laboratory course offered by the Department of Computer Science and Engineering at the University of Asia Pacific.

The course introduces fundamental programming concepts and practical problem-solving techniques using the **C programming language**.

It focuses on developing logical thinking, understanding programming fundamentals, and implementing solutions through hands-on coding exercises.

---

## 🎯 Learning Objectives

- Understand fundamental programming concepts.
- Learn the syntax and structure of C programs.
- Develop logical thinking and problem-solving skills.
- Practice conditional statements and loops.
- Work with arrays, strings, and functions.
- Improve debugging and coding skills.
- Build a strong foundation for advanced programming courses.
