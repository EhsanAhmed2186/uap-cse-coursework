## 🗂️ Course Folder Structure

Each programming course follows a consistent folder structure to keep academic materials organized.

**Example: CSE103 – Structured Programming**

```text

│
├── Labs/
│   └── ...
│
├── Assignments/
│   └── ...
│
├── Practice/
│   └── ...
│
└── README.md
```

### Folder Descriptions

| Folder | Description |
|--------|-------------|
| **Labs/** | Laboratory exercises and implementations |
| **Assignments/** | Academic programming assignments |
| **Practice/** | Additional coding exercises and problem-solving |
| **README.md** | Course overview, topics, and references |

Course-specific folders may be modified according to individual course requirements.

The primary goal of this repository is to maintain a structured archive of my academic learning and technical development throughout my CSE degree.

This repository aims to:

- 📚 Organize academic coursework in one place.
